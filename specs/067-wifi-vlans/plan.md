# Implementation Plan: WAX610 WiFi with Trusted and Guest VLANs

**Branch**: `067-wifi-vlans` | **Date**: 2026-05-26 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/067-wifi-vlans/spec.md`

## Summary

Add WiFi to the lab via a Netgear WAX610 AP with two isolated SSIDs: "fleet1" (VLAN50, trusted clients with fleet1.lan access) and "fleet1-guest" (VLAN60, internet-only isolation). The WAX610 management interface moves to `10.1.1.50` on the wired LAN. OPNsense VLAN interface creation, DHCP configuration, and switch trunk config are one-time manual steps documented in quickstart.md; firewall rules and any supporting Ansible tasks are added to the existing `network-deploy.yml` playbook idempotently.

## Implementation Approach

### What Ansible Handles

Additions to `playbooks/network/network-deploy.yml` using the `oxlorg.opnsense` collection:

**VLAN50 firewall rules** (5 rules, seq 300–304):
- `300` Allow VLAN50 → `10.1.50.1:53` (DNS to OPNsense gateway)
- `301` Allow VLAN50 → `10.1.20.11:30443` TCP (Traefik HTTPS)
- `302` Allow VLAN50 → `10.1.20.11:30883` TCP (Traefik MQTTS)
- `303` Block VLAN50 → `10.1.0.0/8` (all internal)
- `304` Allow VLAN50 → any (internet)

**VLAN60 firewall rules** (3 rules, seq 310–312):
- `310` Allow VLAN60 → `10.1.60.1:53` (DNS to OPNsense gateway)
- `311` Block VLAN60 → `10.1.0.0/8` (all internal)
- `312` Allow VLAN60 → any (internet)

No Unbound DNS changes needed — Unbound already listens on all interfaces and serves `fleet1.lan` overrides globally.

### What Is Manual (documented in quickstart.md)

1. OPNsense: Create VLAN50 and VLAN60 sub-interfaces (web UI)
2. OPNsense: Assign interfaces as opt5/opt6 with static IPs (web UI)
3. OPNsense: Enable DHCP servers for VLAN50 and VLAN60 (web UI)
4. GS308T: Add VLAN50/60 as tagged on GS308EPP uplink port (web UI)
5. GS308EPP: Add VLAN50/60 as tagged on GS308T uplink + port 7 (web UI); set port 7 native VLAN to LAN
6. WAX610: Move management IP to `10.1.1.50` (web UI)
7. WAX610: Create "fleet1" SSID on VLAN50 with client isolation disabled (web UI)
8. WAX610: Create "fleet1-guest" SSID on VLAN60 with client isolation enabled (web UI)

Update `docs/networking.md` VLAN table to add VLAN50 and VLAN60 entries.
