# Implementation Plan: Authentik OIDC App Integration (064)

**Branch**: `064-authentik-oidc-apps` | **Date**: 2026-05-22 | **Spec**: `specs/064-authentik-oidc-apps/spec.md`

## Summary

Add Authentik as a secondary OIDC sign-in option for Grafana, Gitea, and ArgoCD. Native admin logins remain valid as Tier 0 break-glass on all three apps. Changes land via Ansible Helm values template edits (one PR per app), applied by re-running each service's Ansible role. No SealedSecrets needed — these are infrastructure services managed by Ansible, not ArgoCD-managed workloads.

## Implementation Phases

### Phase 0 — Shared Authentik Setup (prerequisite for all apps)

Manual steps in Authentik admin UI. No code committed. Must be done before any app PR.

1. Create `admins` group; create `users` group
2. Add `akadmin` to `admins` group
3. Create `groups-claim` Scope Mapping (Python expression)
4. Generate three client secrets: `openssl rand -hex 32` × 3
5. Add to `group_vars/all.yml` as `grafana_oidc_client_secret`, `gitea_oidc_client_secret`, `argocd_oidc_client_secret`
6. Add CHANGEME placeholders to `group_vars/example.all.yml`

### Phase 1 — Grafana OIDC (PR 1 of 3)

**Authentik side** (UI):
- Create provider `grafana` with `grafana_oidc_client_secret`, redirect URIs for `.lan` + `.cloud`
- Create Application slug `grafana`, attach `groups-claim` scope

**Code change**:
- Add `auth.generic_oauth` section to `roles/kube-prometheus-stack/templates/values.yaml.j2`

**Deploy**:
```bash
ansible-playbook -i hosts.ini playbooks/cluster/services-deploy.yml --tags kube-prometheus-stack \
  -e "ansible_ssh_common_args='-o StrictHostKeyChecking=no'"
```

**Validate**: OIDC login works; akadmin gets Admin role; native admin still works.

### Phase 2 — Gitea OIDC (PR 2 of 3)

**Authentik side** (UI):
- Create provider `gitea` with `gitea_oidc_client_secret`, redirect URIs

## Key Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Secret storage | `group_vars/all.yml` (Ansible rendered) | Infrastructure services; no SealedSecret needed |
| ArgoCD Dex | Already disabled | `dex.enabled: false` already in template |
| Groups claim | Custom scope mapping in Authentik | Explicit > implicit; reliable across versions |
| PR order | Grafana → Gitea → ArgoCD | Ascending risk; OIDC failures easiest to isolate |
| OIDC availability | LAN only | Authentik is `fleet1.lan`; not reachable externally |
